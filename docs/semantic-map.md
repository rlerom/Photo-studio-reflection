# Semantic map - фотостудия «Отражение»

Визуальный блок / содержание
Назначение
Предполагаемый HTML-тег

Верхняя часть страницы с названием студии --> вводная часть сайта --> <header>
Логотип и/или название «Отражение» --> идентификация фотостудии --> <a> или <p>
Главное меню --> переходы по разделам страницы --> <nav>
Ссылки «Услуги», «Портфолио», «Цены», «Контакты» --> навигационные ссылки --> <a> внутри <nav>
Основное содержимое главной страницы --> уникальная информация страницы --> <main>
Первый экран с предложением фото на документы --> основное предложение студии --> <section>
Главный заголовок страницы --> описание страницы и главной услуги --> <h1>
Кнопка «Записаться» --> целевое действие пользователя --> <a> или <button>
Изображение фотографа или фотостудии --> визуально показывает услугу или пространство студии --> <img>
Блок «Услуги» --> перечень услуг фотостудии --> <section>
Карточка услуги --> описание отдельной услуги --> <article>
Блок «Портфолио» --> примеры работ студии --> <section>
Одна работа из портфолио --> отдельный пример работы --> <figure> с <img> и <figcaption>
Блок «Цены» --> информация о стоимости услуг --> <section>
Список цен --> перечень услуг и стоимости --> <table> или <ul>
Блок «Отзывы» --> мнения клиентов о студии --> <section>
Один отзыв --> самостоятельное высказывание клиента --> <article>
Форма записи --> получение заявки от клиента --> <section> и <form>
Поля имени, телефона и услуги --> ввод данных пользователя --> <label> и <input> / <select>
Контактные данные --> способы связи и адрес студии --> <section> или <address>
Нижняя часть страницы --> служебная информация сайта --> <footer>
Технические группы карточек --> объединение элементов для будущего оформления --> <div>
