# Photo-studio-reflection
## Идея проекта
Создать сайт фотостудии «Отражение». Это площадка для знакомства с творчеством студии и её возможностями. Здесь представлены услуги, портфолио с примерами работ, отзывы клиентов, актуальные цены, контакты, адрес и часы работы. Сайт поможет быстрее сориентироваться и выбрать подходящий вариант для фото.
## Планируемый стек
HTML, CSS, JavaScript, PHP, MySQL.
## Запуск
инструкция будет дополняться по мере разработки
